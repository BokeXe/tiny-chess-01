A chess engine in 4 KB of Python: mailbox PVS search with transposition table, null-move pruning, late-move reductions, killers and history heuristics, tapered PeSTO piece-square tables (midgame/endgame), check extensions, quiescence search with repetition detection, and per-opponent node budgets — packed into a 4,093-byte entrypoint with the kit's LZMA compress stub. The readable source is `engine_source.py` (8,807 bytes); `main.py` is its compressed form.

## Run it

```sh
python3 main.py
```
